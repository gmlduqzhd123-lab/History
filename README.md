# 🧭 역사 탐험 퀘스트

초등학교 5학년 2학기 사회(역사) **자기주도 학습 웹앱**입니다.
선생님이 링크만 알려 주면, 학생이 혼자서 자기 속도로 퀘스트를 끝까지 진행합니다.

## 선생님이 할 일
1. 이 앱 주소(GitHub Pages 링크)를 QR 코드로 칠판에 붙여 둡니다.
2. 끝입니다. 진행, 채점, 피드백은 앱이 합니다.

- 학생은 **이름 대신 번호(1~40)** 와 캐릭터로 시작합니다. 서버에 아무것도 보내지 않고, 기록은 그 기기에만 저장됩니다.
- 정거장은 순서대로 열립니다. 결석한 학생 등을 위해 모든 퀘스트를 한꺼번에 열려면 주소 끝에 `?open=all` 을 붙이세요.
- 한 번 연 뒤에는 **인터넷이 끊겨도** 동작합니다(오프라인 지원).

## 학생의 퀘스트 흐름 (정거장 하나, 약 20~25분)
| 단계 | 하는 일 | 앱이 돕는 방법 |
|---|---|---|
| 🔍 유물 탐정 | 가려진 유물 그림을 보고 쓰임과 시대를 추리 | 단서를 볼 때마다 그림이 드러남, 오답마다 맞춤 설명 |
| 📖 이야기 카드 | 짧은 글 읽기 → 확인 문제 | 🔊 읽어 주기, 핵심어 강조, 바로 넘기기 방지 |
| 🎲 생활 체험 | 그 시대 아이가 되어 선택하는 이야기 | 선택마다 역사적 이유 설명 |
| 🏆 개념 도전 | 5문제 중 4문제 이상 한 번에 맞히면 통과 | 🙋 힌트(오답 하나 지우기), 틀린 개념은 비슷한 문제로 한 번 더, 불통과 시 요점 다시 보기 |
| 📝 한 줄 정리 | 문장 틀의 빈칸 채우기 | 핵심어 자동 확인, 낱말 상자, 예시 답 |

- **찍기 방지:** 너무 빠르게 연달아 틀리면 잠깐 멈추고 해설을 읽게 합니다.
- **💾 이어하기 코드:** 10글자 코드로 다른 기기에서도 진도를 이어 갑니다(한 줄 정리 글은 옮겨지지 않음).
- **📒 나의 역사 노트:** 모은 유물 도감과 한 줄 정리를 인쇄하거나 PDF로 저장합니다.

## 선생님 검수 체크리스트
콘텐츠는 교과서 용어에 맞춰 썼지만, 수업 전에 사용하시는 교과서와 한 번 대조해 주세요.
- 연대: 구석기 약 70만 년 전, 신석기 약 1만 년 전
- 신석기: 간석기, 빗살무늬 토기, 가락바퀴·뼈바늘, 조·피·수수 농사, 움집(서울 암사동)
- 청동기: 벼농사 시작, 반달 돌칼, 민무늬 토기, 빈부의 차이와 계급, 고인돌(고창·화순·강화 세계 유산)
- 고조선: 단군왕검(『삼국유사』), 홍익인간, 8조법 중 3개 조항, 비파형 동검·탁자식 고인돌로 세력 범위 짐작
- 유물 그림은 이해를 돕기 위해 직접 그린 그림입니다(실제 사진 아님).

## 파일 구조 (콘텐츠 추가 방법)
```
index.html               앱 시작 파일
css/style.css            디자인
js/app.js                화면 전환, 지도, 노트, 이어하기
js/activities/*.js       다섯 가지 활동 (detective, reading, adventure, mastery, summary)
js/art.js                유물 그림(SVG)
content/quests.js        탐험 지도 (단원·정거장 목록)
content/q1-stone-age.js  퀘스트 1 내용
content/q2-bronze-gojoseon.js  퀘스트 2 내용
sw.js                    오프라인 지원
```
새 퀘스트를 만들 때는 `content/q1-stone-age.js`를 복사해서 내용을 바꾸고, `content/quests.js`의 해당 정거장에 `quest: ...`로 연결하세요. 새 파일은 `sw.js`의 `FILES` 목록에도 추가하고, `CACHE` 이름의 숫자를 올려 주세요.
⚠️ `content/quests.js`의 정거장 **순서**는 이어하기 코드와 연결되어 있으니 바꾸지 마세요.

## 배포
빌드 과정이 없는 순수 HTML/JS입니다. 저장소 설정 → Pages에서 `main` 브랜치의 루트(`/`)를 선택하면 바로 배포됩니다.
